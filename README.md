# 7hillswebmasters website

## Not technical? Start here

Your ready-to-upload website is in the folder:

**`UPLOAD-THIS-WEBSITE`**

Or download the zip:

**`7hillswebmasters-website.zip`**

1. Open `UPLOAD-THIS-WEBSITE/START-HERE.txt` for simple steps
2. Double-click `index.html` to preview
3. Upload the folder to any web host (Hostinger, GoDaddy, Netlify Drop, etc.)

No command prompt. No installation. No GitHub knowledge needed.
